# References

`references.bib` contains the 20 bibliography records currently maintained for
the project. `papers/` contains the three locally available reference PDFs:

- `liu2024_audiomarkbench.pdf`: AudioMarkBench.
- `oreilly2025_deep_audio_watermarks_are_shallow.pdf`: analysis of post-hoc
  speech watermarking.
- `yao2026_overwriting_attacks_neural_audio_watermarking.pdf`: overwriting
  attacks against neural audio watermarking.

The PDFs are reference material only. They are not project outputs and remain
subject to their publishers' copyright terms.
